# Каратэ-клуб — личный кабинет спортсмена

Домашняя работа 8 по веб-технологиям. Одностраничное приложение на React +
TypeScript: регистрация, вход, выход, просмотр и редактирование своего профиля.
Тема — каратэ-клуб. Автор: Асанбеков Байбол.
Бэкенд предоставлен преподавателем.

Живая версия: https://baibolasanbekov.github.io/karate-club/

## Что умеет

- регистрация нового спортсмена (логин и пароль от 6 символов);
- вход и выход;
- просмотр своего профиля: имя, направление, рассказ о себе, стоимость занятия;
- редактирование профиля, направление выбирается из списка, который отдаёт сам
  сервер;
- человеческие сообщения об ошибках вместо кодов.

| `src/api.ts` | все обращения к серверу, типы и разбор ошибок |

### Авторизация

Сервер узнаёт пользователя по куке `sessionid`, которую сам ставит при входе.
Кука помечена `HttpOnly`, то есть из JavaScript не читается — браузер
прикладывает её сам, но только если запрос разрешает отправку кук. Поэтому в
каждом `fetch` стоит `credentials: "include"`; без этой строки защищённые адреса
отвечают `403 Учетные данные не были предоставлены`.

Заголовок `Session-Id`, который предлагает документация, из браузера не
работает: сервер не перечисляет его в `Access-Control-Allow-Headers`, и запрос с
чужого домена гибнет на префлайте. Рабочий способ ровно один — кука.

CSRF-токен для `PATCH` не нужен, проверено запросом.

### Адреса сервера

База: `https://inai-col2.fishrungames.com`

| Метод и адрес | Что делает |
| --- | --- |
| `POST /api/register/` | регистрация, сразу открывает сессию |
| `POST /api/login/` | вход |
| `POST /api/logout/` | выход |
| `GET /api/profile/` | свой профиль |
| `PATCH /api/profile/` | изменить свой профиль |
| `GET /api/specializations/` | список специализаций, без авторизации |

Стоимость занятия сервер возвращает строкой вида `"2500.00"`. Дробную часть принимает
только через точку: `"2500,50"` отвергается с «Требуется численное значение.»,
поэтому запятую приложение заменяет само.

## Запуск

```
npm install
npm run dev
```

Откроется `http://localhost:5173/karate-club/`. Этот адрес серверу разрешён, так
что вход работает и при локальной разработке.

Сборка:

```
npm run build
```

## Деплой

Пушим в ветку `main` — дальше GitHub Actions собирает проект и публикует папку
`dist` на GitHub Pages. В настройках репозитория источник Pages должен стоять
`GitHub Actions`.

Имя репозитория зашито в `vite.config.ts` строкой `base: '/karate-club/'`.
Назовёшь репозиторий иначе — поменяй и её, иначе стили и скрипты будут
искаться не по тому пути и страница откроется пустой.

## Про тему и сервер

Сервер общий и рассчитан на другую тему: значения специализаций (`vocals`,
`guitar`, `bass`, `drums`, `keys`, `other`) менять нельзя. Поэтому для темы
каратэ в `src/api.ts` подменяются только подписи на экране (Тренер, Ката,
Кумитэ, Кихон, Судья, Другое), а на сервер уходит исходное значение.
